# Small Wins

A tiny daily checklist for keeping track of what matters. Add a task, mark it
done, and come back later: your list stays in this browser using local storage.

## Run it

Open `index.html` in a browser. There are no dependencies or build steps.

## Features

- Add and complete daily tasks
- Keep your list between visits
- See your progress at a glance
- Clear completed tasks when you are ready for a fresh start
